# MindEase AI 🌿

MindEase AI is a mental wellness application built using React.

## Features

- User Login
- Mood Tracking
- Wellness Dashboard
- AI Support Chat
- Responsive Mobile UI

## Tech Stack

- React
- React Router DOM
- CSS
- Vite

## Screens

- Splash Screen
- Login Screen
- Mood Tracker
- Dashboard
- Chat Interface

## Future Enhancements

- Node.js Backend
- MongoDB Integration
- JWT Authentication
- AI-powered Mental Wellness Assistant
